# ميزانيتي 💰

تطبيق لتسجيل الدخل والمصروفات اليومية من **أكتوبر ٢٠٢٦ حتى ديسمبر ٢٠٢٧**.
يشتغل بدون إنترنت، وبياناتك تتحفظ على جهازك.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كله |
| `manifest.json` | بيانات التثبيت (الاسم، الألوان، الأيقونات) |
| `sw.js` | تشغيل التطبيق بدون إنترنت |
| `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` | الأيقونات |

## الخطوة ١: الرفع على GitHub Pages

1. ادخل على github.com وسجّل دخول، ثم اضغط **New repository**.
2. اكتب اسم للمشروع (مثلًا `budget`)، واختر **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، واسحب **كل الملفات** (بعد فك الضغط) وليس المجلد نفسه، ثم **Commit changes**.
4. من **Settings ← Pages**: في Source اختر **Deploy from a branch**، وفي Branch اختر `main` و `/ (root)`، ثم **Save**.
5. بعد دقيقة أو اتنين هيظهر الرابط بالشكل ده:
   `https://اسم-المستخدم.github.io/budget/`

## الخطوة ٢: التثبيت على الموبايل (بدون APK)

افتح الرابط من **Chrome** على الأندرويد، واضغط ⋮ ثم **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
هيظهر بأيقونة وشاشة كاملة زي أي تطبيق، وبيشتغل بدون إنترنت.

## الخطوة ٣: تحويله إلى APK

1. افتح **pwabuilder.com** وحط رابط التطبيق، ثم **Start**.
2. اضغط **Package for Stores** ثم اختار **Android**.
3. اكتب اسم التطبيق (`ميزانيتي`) ومعرّف الحزمة (مثلًا `com.yourname.budget`)، وخلّي **Signing key** على **Create new**.
4. اضغط **Download**، وهتلاقي في الملف المضغوط ملف الـ APK وملف مفتاح التوقيع وشرح الخطوات.
5. انقل الـ APK للموبايل وافتحه. لو طلب الأندرويد السماح بالتثبيت من مصدر غير معروف، وافق.

**مهم:**
- احتفظ بملف مفتاح التوقيع وكلمة سره في مكان آمن، لأنك هتحتاجهم لتحديث التطبيق بعد كده.
- ظهور شريط العنوان أعلى التطبيق طبيعي لو مفيش ملف `assetlinks.json`. لو عايز تخفيه، اسم المشروع على GitHub لازم يكون `اسم-المستخدم.github.io`، وتحط الملف في مجلد `.well-known` (PWABuilder بيشرح الخطوات).
- بيانات التطبيق محفوظة على الجهاز، فلو مسحت بيانات المتصفح أو التطبيق هتضيع.

## تعديل التطبيق لاحقًا

بعد أي تعديل في الملفات، غيّر رقم النسخة في أول `sw.js` (مثلًا `budget-v2`) عشان الموبايل يحمّل التحديث.
